# Academic Homepage Template

If you like this template or wish to use it, please consider giving this repository a star.

这是一个静态 academic homepage / research workspace 模板。它支持 About、Notes、Memos、论文阅读摘要、Daily Paper、Zotero Paper List、Giscus 评论，以及由 Supabase 提供的 realtime memo/star/archive 状态。

- 在线示例：[junle.site](https://junle.site)
- 源码仓库：[junle-chen/ac-homepage](https://github.com/junle-chen/ac-homepage)

主要说明请看 [README.md](README.md)，其中包含：

- 最新网页截图和 About / Memos / Academic / Notes reader 功能说明
- 本地运行方式
- `config.json`、头像、About、Notes 和 paper 数据的替换入口
- Supabase realtime、GitHub OAuth、memos、paper stars 和 archive 状态实现
- Giscus GitHub Discussions 评论配置
- GitHub Pages 部署方式
- 使用到的网站、服务、库和上游模板来源
- `LICENSE`、`NOTICE.md`、`ATTRIBUTION.md` 中的代码许可证与上游署名说明

如果这个模板对你有帮助，给仓库一个 star 就可以了。
